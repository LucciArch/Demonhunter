# Dämonenjäger

Ein Incremental-Spiel im Stil von *Loot Loop*: kurze Jagden, Dämonen vernichten, Seelen sammeln und einen riesigen Schwurbaum ausbauen.

## Spielen
**Windows:** Unter [Releases](../../releases/latest) die `Daemonenjaeger-…-portable.exe` herunterladen und starten (oder die `-setup.exe` zum Installieren). Jeder Push auf `main` baut automatisch eine neue Version.

**Browser:**
`index.html` im Browser öffnen. Das Spiel kommt ohne Build-Schritt aus und speichert lokal im Browser.

## Inhalt
- 5 spielbare Jäger: Inquisitor, Hexenjägerin, Exorzistin, Blutjäger, Runenschmiedin
- Schwurbaum mit 6 Pfaden (Klinge, Wille, Zeit, Gier, Bann, Okkult)
- Endlose Höllenkreise mit Fürsten-Bossen
- 3 Währungen: Seelen, Schwefel, Siegel
- Handgepixelte Sprites, direkt im Code gezeichnet
